Теңбүйірлі үшбұрыш,
оның қасиеттері мен белгілері

Егер үшбұрыштың екі қабырғасы тең болса ($a = b$), ол теңбүйірлі үшбұрыш деп аталады. Тең қабырғалары — бүйір қабырғалары, ал үшінші қабырғасы — табаны деп аталады.

Бүйір қабырғалары (a = b)
Табанындағы бұрыштар (∠A = ∠B)
Биіктік = Медиана = Биссектриса
Теңбүйірлі ΔABC AC = BC

Интерактивті Визуалды Лаборатория

Табаны ($c$) мен бүйір қабырғасын ($a$) өзгертіп, үшбұрыштың элементтерін, биіктігін және периметрін бақылаңыз.

Теңбүйірлі ΔABC: b = a = 140 px, c = 160 px
P = 440 px S = 9165 px²

Үшбұрыш құрастыру мүмкін емес!

Бүйір қабырғаларының қосындысы табанынан үлкен болуы тиіс ($a + b > c$).

Табанына жүргізілген CH кесіндісі - әрі БИІКТІК (CH⊥AB), әрі МЕДИАНА (AH=HB), әрі БИССЕКТРИСА (∠ACH=∠BCH)!

Қасиеттері мен Белгілері Конструкторы

Теоремаларды таңдап, интерактивті түсіндірмесі мен математикалық дәлелдеу алгоритмін оқыңыз.

1-Теорема (Бұрыш қасиеті)

Табанындағы бұрыштардың теңдігі

Теңбүйірлі үшбұрыштың табанындағы бұрыштары өзара тең болады.

Дәлелдеу идеясы:

1. C төбесінен CD биссектрисасын жүргіземіз (∠ACD = ∠BCD).
2. ΔACD мен ΔBCD үшбұрыштарын қарастырамыз:
  • AC = BC (анықтама бойынша)
  • CD — ортақ қабырға
  • ∠ACD = ∠BCD
3. ТҚТ (1-белгі) бойынша: ΔACD = ΔBCD.
4. Демек, сәйкес бұрыштар тең: ∠A = ∠B.

∠A = ∠B (Тең)
2-Теорема (Сәйкестену қасиеті)

Үш кесіндінің беттесуі

Теңбүйірлі үшбұрыштың табанына жүргізілген биіктігі, медианасы және биссектрисасы беттеседі (бір кесінді болады).

  • Биіктік ретінде: CH ⊥ AB (табанына перпендикуляр).
  • Медиана ретінде: AH = HB (табанын қақ бөледі).
  • Биссектриса ретінде: ∠ACH = ∠BCH (төбедегі бұрышты қақ бөледі).
CH кесіндісі 3 рөлді де атқарады:
Биіктік (h) Медиана (m) Биссектриса (l)
Кері теоремалар

Үшбұрыштың теңбүйірлік белгілері

Егер берілген белгісіз үшбұрышта төмендегі шарттардың біреуі орындалса, ол міндетті түрде теңбүйірлі болады:

  • 1-Белгі (Бұрыш бойынша): Егер үшбұрыштың екі бұрышы тең болса (∠A = ∠B), ол теңбүйірлі үшбұрыш.
  • 2-Белгі (Кесінділер бойынша): Егер үшбұрыштың медианасы әрі биіктігі болса (немесе биссектрисасы әрі биіктігі болса), ол теңбүйірлі.
Тексеру ережесі

Екі бұрыштың теңдігін көре салысымен, оларға қарсы жатқан қабырғаларды тең деп қорытынды жасауға болады!
